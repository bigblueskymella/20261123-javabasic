개념 1. 배열과 ArrayList는 무엇이 다를까?

먼저 복습 — 일반 배열로 아이템 3개 관리하기

4회차에서 배운 배열을 떠올려 봅시다. 배열은 여러 값을 순서대로 저장하고 인덱스 0부터 접근합니다. 아래 예제는 새 문법 없이 직접 입력할 수 있습니다.

파일: ArrayReview.java

java · 직접 입력
public class ArrayReview {
  public static void main(String[] args) {
    String[] items = {"검", "방패", "물약"};
    for (int i = 0; i < items.length; i++) {
      System.out.println((i + 1) + ". " + items[i]);
    }
  }
}

실행 전에 예측하기: 화면의 1번 아이템은 배열의 몇 번째 인덱스일까요? 방패 이름을 활로 바꾸려면 어떤 줄을 추가하면 될까요?

교사용 정답 보기 · 일반 배열 복습
java · 정답 코드
items[1] = "활";

이번에는 아이템을 하나 더 추가하려고 합니다. 이미 만든 배열의 길이를 실행 중에 직접 늘릴 수는 없습니다. 새 배열을 만들고 복사할 수도 있지만, 추가·삭제가 잦으면 불편합니다. 그래서 크기를 바꿀 수 있는 ArrayList를 사용합니다.

비교 — 배열과 ArrayList

배열은 items.length로 길이를 확인하고 items[0]처럼 접근합니다. ArrayList는 items.size()로 항목 수를 확인하고 items.get(0)으로 접근합니다. ArrayList에 항목을 추가할 때는 add(), 삭제할 때는 remove()를 씁니다.

배열은 생성할 때 크기가 정해집니다. ArrayList는 add()로 항목을 더하고 remove()로 삭제할 수 있는 목록입니다.

java
ArrayList<String> cart = new ArrayList<>(); // 문자열 목록 생성
cart.add("아이스티"); // 맨 뒤에 추가
System.out.println(cart.size()); // 항목 개수
System.out.println(cart.get(0)); // 첫 번째 항목

ArrayList를 쓰려면 파일 맨 위에 import java.util.ArrayList;가 필요합니다. cart.size()는 수량 합계가 아니라 목록 항목 수입니다.

삭제를 하기 전에 remove()를 먼저 연습합니다.

java
ArrayList<String> drinks = new ArrayList<>();
drinks.add("아이스티");
drinks.add("초코라테");
drinks.add("레몬에이드");
drinks.remove(1); // 인덱스 1인 초코라테 삭제
System.out.println(drinks.get(1)); // 이제 레몬에이드

remove(1)에서 1은 사람이 보는 '1번 메뉴'가 아니라 인덱스 1, 즉 두 번째 항목이라는 점에 주의합니다.

실습 2. 여러 주문의 금액 합산

파일: Cart.java

앞의 실습에서는 String 배열과 ArrayList<String>으로 이름만 관리했습니다. 실제 주문은 이름·가격·수량을 함께 기억해야 하므로 6회차에서 배운 클래스를 사용합니다. Order 객체 하나를 먼저 만들고 sum(cart)를 호출해 본 뒤, 여러 Order를 ArrayList에 넣습니다.

sum(cart)는 무엇일까?

`sum(cart)`는 주문 목록 전체를 전달받아 가격 × 수량을 모두 더하는 메서드입니다. `Order`는 음료 한 건의 이름·가격·수량만 저장하고, 계산은 Cart의 sum()에서 담당합니다.

java · Order 클래스 안에 정의된 메서드 사용 예시
Order one = new Order("아이스티", 3000, 2);
System.out.println(one.price * one.qty); // 6000

amount는 자바에서 정해 놓은 명령이 아니라 우리가 직접 만드는 메서드 이름입니다. 한 주문의 금액인 가격(price) × 수량(qty)을 계산해서 돌려주도록 작성합니다.

java · Order 클래스 먼저 읽기
class Order {
  String name;
  int price;
  int qty;

  Order(String name, int price, int qty) {
    this.name = name;
    this.price = price;
    this.qty = qty;
  }
}

// 장바구니를 합산하는 메서드는 다음 실습에서 작성합니다.
// sum(cart)는 주문 목록 전체의 금액을 계산해 반환합니다.

예를 들어 아이스티 3,000원을 2잔 주문했다면 sum(cart)의 결과는 6,000입니다. 앞 회차에서 배운 return처럼 계산한 값을 호출한 곳으로 돌려줍니다.

for (Order order : cart)는 cart에 있는 주문을 하나씩 꺼내 order 변수에 넣는 문장입니다. 파이썬의 for order in cart:와 비슷합니다. 일반 for문과 달리 인덱스 번호를 따로 계산하지 않아도 됩니다.

public class Cart {
  static int sum(ArrayList<Order> cart) {
    int total = 0;

      // TODO: 가격과 수량을 곱해 합계에 더하세요.
    }
    return total;

  public static void main(String[] args) {

실습 3. 주문 번호로 삭제

파일: CartEdit.java

화면에는 장바구니 번호가 1번부터 표시되지만, ArrayList의 인덱스는 0부터 시작합니다. 따라서 1번을 취소하려면 remove(0)을 사용해야 합니다. 주문 번호가 0이거나 목록 범위를 벗어나면 삭제하지 않아야 합니다.

아래 코드를 함께 입력한 뒤, TODO 한 줄을 완성하세요. 프로그램을 다시 실행하면서 1, 0, 3, -1을 각각 입력해 보세요. (처음 장바구니에는 음료 2개가 있습니다.)

CartEdit.java · 함께 입력
import java.util.ArrayList;
import java.util.Scanner;

public class CartEdit {
  static class Order {
    String name;
    int price;
    int qty;

    Order(String name, int price, int qty) {
      this.name = name;
      this.price = price;
      this.qty = qty;
    }
  }

  public static void main(String[] args) {
    ArrayList<Order> cart = new ArrayList<>();
    cart.add(new Order("아이스티", 3000, 2));
    cart.add(new Order("초코라테", 3500, 1));
    Scanner sc = new Scanner(System.in);

    for (int i = 0; i < cart.size(); i++) {
      Order order = cart.get(i);
      System.out.println((i + 1) + ". " + order.name
          + " " + order.qty + "잔");
    }

    System.out.print("취소할 번호(0은 취소 안 함): ");
    int num = sc.nextInt();
    if (num >= 1 && num <= cart.size()) {
      // TODO: 선택한 주문 객체를 삭제하세요.
      System.out.println("취소 완료");
    } else if (num == 0) {
      System.out.println("주문을 유지합니다.");
    } else {
      System.out.println("없는 주문 번호입니다.");
    }

    for (Order order : cart) {
      System.out.println(order.name + " " + order.qty + "잔");
    }
    sc.close();
  }
}
