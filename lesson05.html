개념 먼저 배우기 — 메서드는 이름 붙인 작업

같은 동작을 여러 번 써야 한다면 코드를 하나의 이름으로 묶어 호출할 수 있습니다. 이를 메서드라고 합니다.

java
public class MethodIntro {
  static void hello() { // 메서드 정의: 무슨 일을 할지 작성
    System.out.println("안녕하세요!");
  }
  public static void main(String[] args) {
    hello(); // 메서드 호출: 실제 실행
    hello(); // 같은 메서드를 한 번 더 실행
  }
}
  • void는 결과값을 돌려주지 않고 작업만 수행한다는 뜻입니다.
  • hello()처럼 괄호를 붙이면 해당 메서드를 호출합니다.
  • 이번에는 main()에서 바로 호출할 수 있도록 static을 붙입니다. 소속 개념은 클래스와 객체 단원에서 설명합니다.
  • 파일명을 MethodIntro.java로 저장하고 실행합니다.

실습 1. 메서드 첫 사용

이번에는 괄호 안에 이름을 전달하는 메서드를 사용합니다.

Method.java

java
public class Method {
  static void greet(String name) {
    // void: 돌려주는 결과 없이 실행만 한다.
    System.out.println(name + "님, 환영합니다.");
  }
  public static void main(String[] args) {
    greet("민수");
    greet("지연");
  }
}

코드를 입력하며 확인할 점

  • name은 메서드가 전달받는 값(매개변수)입니다.
  • 지금은 main에서 바로 호출하기 위해 static을 사용합니다. 클래스와 객체를 배운 뒤 다시 설명합니다.

개념 먼저 배우기 — 매개변수와 return

메서드는 계산에 필요한 값을 매개변수로 받아 사용하고, return으로 결과를 호출한 곳에 돌려줄 수 있습니다.

java
static int doubleIt(int number) { // int 결과를 돌려주는 메서드
  return number * 2; // 결과를 반환하고 종료
}
// main 안에서 호출하는 예:
System.out.println(doubleIt(4)); // 8

return은 단순히 화면에 출력하는 명령이 아닙니다. 결과를 다른 코드에서 다시 사용할 수 있게 전달하는 명령입니다.

실습 2-1. 카페에서 받은 주문으로 총금액 계산하기

앞에서는 음료 한 종류의 가격 × 수량을 계산했습니다. 이번에는 손님이 아이스티, 초코라테, 딸기라테를 각각 몇 잔 주문했는지 입력받고, 음료별 주문금액을 합산해 봅니다.

코드 입력 전 생각하기

  1. 아이스티 2잔, 초코라테 1잔, 딸기라테 1잔이라면 총금액은 얼마일까요?
  2. 이미 만든 total(price, count) 메서드를 음료마다 재사용할 수 있을까요?
  3. 음료별 주문금액 세 개를 하나의 총금액으로 만들려면 어떤 연산이 필요할까요?

입력 예: 아이스티 2잔, 초코라테 1잔, 딸기라테 1잔 → 총 결제금액: 13500원

CafeTotal.java

java
import java.util.Scanner;
public class CafeTotal {
  static int total(int price, int count) {
    return price * count;
  }
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    System.out.print("아이스티 수량: ");
    int icedTea = sc.nextInt();
    System.out.print("초코라테 수량: ");
    int chocolate = sc.nextInt();
    System.out.print("딸기라테 수량: ");
    int strawberry = sc.nextInt();
    // 앞에서 만든 total(가격, 수량) 메서드를 재사용합니다.
    int teaTotal = total(3000, icedTea);
    int chocoTotal = total(3500, chocolate);
    int berryTotal = total(4000, strawberry);
    // TODO 1: 세 음료의 주문금액을 더해 sum에 저장하세요.
    int sum = 0;
    // TODO 2: sum을 이용해 총 결제금액을 출력하세요.
    sc.close();
  }
}

먼저 TODO 1과 TODO 2를 직접 완성하고 실행하세요. 수량을 2, 1, 1로 입력하면 13,500원이 출력되어야 합니다.

데미지 계산 전: 음수 막기

방어력이 공격력보다 높으면 공격력 - 방어력이 음수가 됩니다. 먼저 결과를 변수에 저장한 다음 if로 0보다 작은지 확인합니다. 이것이 지금까지 배운 문법만으로 해결하는 방법입니다.

java · 함께 입력
int damage = 5 - 15;
if (damage < 0) {
  damage = 0;
}
System.out.println(damage); // 0

이와 같은 방법으로 Battle.java에서 return할 값을 계산해 보세요. Math.max()는 다 풀고 난 뒤 참고하면 됩니다.

앞에서 배운 메서드를 이용해 햄버거·감자튀김·콜라를 각각 주문하는 프로그램을 만듭니다. 먼저 메뉴를 개별 주문하고, 세트 할인은 기본 실습을 끝낸 뒤 추가 문제로 풀어 봅니다.
