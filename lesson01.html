먼저 파이썬과 비교해 보기

파이썬의 print("안녕")과 자바의 System.out.println("안녕");은 둘 다 화면에 글자를 출력합니다. 자바에서는 문장 끝의 세미콜론(;)과 문자열의 큰따옴표를 확인하세요.

java · 함께 입력
System.out.println("안녕");

public class와 main은 프로그램을 시작하는 틀입니다. 오늘은 그대로 입력하고, 클래스의 의미는 6회차에서 살펴봅니다.

실습 1. 처음 출력하기

학생이 아래 코드를 처음부터 전부 입력합니다. 실행 결과를 먼저 예상하세요.

Hello.java

java
public class Hello {
  public static void main(String[] args) {
    // println: 출력한 뒤 줄을 바꾼다.
    System.out.println("자바 수업 시작!");
    // print: 출력 후 같은 줄에 다음 글자가 이어진다.
    System.out.print("오늘의 메뉴: ");
    System.out.println("아이스티");
  }
}

코드를 입력하며 확인할 점

  • main은 프로그램이 시작되는 메서드입니다. 정확한 선언 이유는 6회차에서 정리합니다.
  • 따옴표 안은 글자이며, 명령문 끝에는 세미콜론(;)이 필요합니다.

실습 2. 캐릭터 정보

캐릭터 이름과 HP를 직접 수정해 실행 결과를 확인합니다.

Hero.java

java
public class Hero {
  public static void main(String[] args) {
    String name = "용사"; // 문자열
    int hp = 100; // 정수
    System.out.println(name + " HP: " + hp);
    // HP를 바꾸고 위의 출력을 다시 사용해 보세요.
    hp = 75;
    System.out.println(name + " HP: " + hp);
  }
}

코드를 입력하며 확인할 점

  • =는 오른쪽 값을 왼쪽 변수에 저장합니다.
  • +는 문자열과 값을 이어 출력할 때도 사용할 수 있습니다.
