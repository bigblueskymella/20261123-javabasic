개념 먼저 배우기 — 배열과 인덱스

배열은 같은 종류의 값을 여러 개 보관하는 자료형입니다. 하나씩 변수를 만드는 대신 번호로 접근합니다.

java
String[] drinks = {"아이스티", "초코라테", "레몬에이드"};
System.out.println(drinks[0]); // 첫 번째: 아이스티
System.out.println(drinks[1]); // 두 번째: 초코라테
System.out.println(drinks.length); // 항목 수: 3

자바 배열의 번호(인덱스)는 0부터 시작합니다. 따라서 항목이 3개라면 인덱스는 0, 1, 2입니다. drinks[3]을 읽으면 실행 중 오류가 납니다.

다음은 이미 배운 for와 결합한 예제입니다.

java
for (int i = 0; i < drinks.length; i++) {
  System.out.println(drinks[i]);
}

먼저 풀기: i < drinks.length 대신 i <= drinks.length를 쓰면 왜 잘못될까요? 결과를 예상한 뒤 확인합니다.

실습 1. 배열로 메뉴 출력

세 가지 음료를 배열에 저장합니다.

Items.java

java
public class Items {
  public static void main(String[] args) {
    String[] names = {"아이스티", "초코라테", "레몬에이드"};
    int[] prices = {3000, 3500, 3500};
    for (int i = 0; i < names.length; i++) {
      System.out.println(i + ": " + names[i] + " " + prices[i] + "원");
    }
  }
}

코드를 입력하며 확인할 점

  • 배열의 첫 칸은 0, 마지막 칸은 length - 1입니다.
  • names[i]와 prices[i]는 같은 번호의 음료를 나타냅니다.

개념 먼저 배우기 — 문자열의 내용 비교

문자열은 숫자처럼 ==로 내용을 비교하지 않습니다. equals()는 글자 내용이 같은지 확인하고 참(true) 또는 거짓(false)을 반환합니다.

java
String drink = "아이스티";
System.out.println(drink.equals("아이스티")); // true
System.out.println(drink.equals("레몬에이드")); // false

또 boolean found = false는 아직 찾지 못했다는 상태를 기록합니다. !found는 found가 false일 때 참입니다.

java
boolean found = false;
if (!found) {
  System.out.println("아직 찾지 못했습니다.");
}

검색 연습 전: 찾았는지 기억하는 변수

반복문은 배열에서 항목을 하나씩 검사합니다. 찾았으면 found를 true로 바꿉니다. 반복이 끝나기 전에는 없는 메뉴라는 메시지를 출력하지 않습니다.

java · 함께 입력
boolean found = false;
String keyword = "아이스티";
String[] names = {"아이스티", "초코라테"};
for (int i = 0; i < names.length; i++) {
  if (names[i].equals(keyword)) {
    found = true;
    break;
  }
}
if (!found) {
  System.out.println("없는 메뉴입니다.");
}

파이썬의 ==와 달리 자바 String의 내용 비교에는 equals()를 사용합니다.
