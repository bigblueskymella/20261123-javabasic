while (true)는 저절로 끝나지 않습니다. break는 자신을 둘러싼 가장 가까운 반복문을 즉시 종료합니다. return은 메서드를 종료하므로 둘을 구분하세요.

이 문법을 잊었다면 3회차에서 직접 실행한 다음 예제를 다시 확인합니다.

java
int turn = 0;
while (true) {
  turn++;
  if (turn == 2) { // 두 번째 실행에서 반복문 종료
    break;
  }
}
System.out.println(turn); // 2

이제 주문 번호 0을 종료 조건으로 바꾸어 적용합니다.

6~7회차 연결: 상품 한 건은 Order 객체에 이름·가격·수량을 저장합니다. 여러 Order를 ArrayList에 넣고, 총액은 sum(cart) 메서드가 계산합니다. 각 주문의 금액은 order.price * order.qty입니다.

실습 1. 여러 번 주문받기

주문이 들어오면 장바구니 전체 금액을 합산해 바로 출력합니다. 합계는 아직 메서드로 분리하지 않고 반복문으로 계산합니다. 다음 실습에서 같은 계산을 sum() 메서드로 옮겨 봅니다.

파일: Kiosk1.java · 08_키오스크_주문/Kiosk1.java

아래 코드를 파일에 입력하고 TODO를 완성한 뒤 실행하세요.

java · 실습 코드
import java.util.ArrayList;
import java.util.Scanner;

public class Kiosk1 {
  static class Order {
    String name;
    int price;
    int qty;

    Order(String name, int price, int qty) {
      this.name = name;
      this.price = price;
      this.qty = qty;
    }
  }

  // 장바구니에 있는 모든 주문금액 계산
  static int sum(ArrayList<Order> cart) {
    int total = 0;
    for (Order order : cart) {
      total += order.price * order.qty;
    }
    return total;
  }

  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    ArrayList<Order> cart = new ArrayList<>();
    String[] names = {"아이스티", "초코라테", "레몬에이드"};
    int[] prices = {3000, 3500, 3500};

    while (true) {
      System.out.println("1. 주문  2. 장바구니  0. 종료");
      int action = sc.nextInt();
      // TODO: 0번이면 반복을 종료하세요.

      if (action == 1) {
        for (int i = 0; i < names.length; i++) {
          System.out.println((i + 1) + ". " + names[i]
              + " " + prices[i] + "원");
        }
        System.out.print("메뉴 번호: ");
        int num = sc.nextInt();
        System.out.print("수량: ");
        int qty = sc.nextInt();

        if (num >= 1 && num <= names.length && qty > 0) {
          cart.add(new Order(names[num - 1], prices[num - 1], qty));
          System.out.println("주문을 담았습니다.");
          System.out.println("현재 총금액: " + sum(cart) + "원");
        } else {
          System.out.println("입력값을 확인하세요.");
        }
      } else if (action == 2) {
        for (Order order : cart) {
          System.out.println(order.name + " " + order.qty
              + "잔 / " + (order.price * order.qty) + "원");
        }
        System.out.println("장바구니 총금액: " + sum(cart) + "원");
      } else {
        System.out.println("없는 기능입니다.");
      }
    }
    sc.close();
  }
}

  1. 우선 메뉴가 반복해서 출력되는지 확인합니다.
  2. TODO의 종료 조건을 학생이 작성합니다.
  3. 주문 두 번 → 장바구니 확인 → 종료 순서로 시험합니다.
  4. 수량이 0이나 음수일 때 어떻게 되는지 확인하고 필요한 검사를 생각합니다.

직접 해 볼 입력: 1 → 아이스티(1번) 2잔 → 1 → 초코라테(2번) 1잔 → 2 → 0. 예상 합계는 9,500원입니다.

AI 질문 예시: “아이스티를 두 번 주문하면 장바구니에 두 줄이 생깁니다. 같은 음료는 한 줄로 묶고 수량을 더하고 싶습니다. ArrayList, for, if, equals()로 해결하는 최소 수정안을 보여주고 바뀐 줄의 이유를 설명해 주세요.”

문제 상황: 아이스티 1잔을 주문한 다음 아이스티 2잔을 다시 주문하면 장바구니에 아이스티가 두 줄로 표시됩니다. 같은 음료는 한 줄에 모으고 수량을 합치도록 바꿔 봅시다.

먼저 직접 확인: 아이스티 1잔 → 아이스티 2잔 → 장바구니 조회. 현재 코드에서는 아이스티가 두 줄이고 전체 수량은 3잔, 합계는 9,000원입니다.

AI에게 질문하기: 아래의 주문 추가 부분을 보여주고 “왜 동일한 메뉴가 별도 항목으로 추가되나요? ArrayList, for문, equals()만 사용해서 기존 수량을 증가시키는 최소 변경 코드를 설명해 주세요. if·for 중괄호는 생략하지 마세요.”라고 질문하세요.

AI의 코드를 그대로 붙여 넣지 말고, 기존 주문을 찾았는지 기록하는 변수와 실제로 수량을 변경하는 부분을 먼저 확인하세요. 그런 다음 기존 cart.add(...) 부분을 수정합니다.

테스트: 아이스티 1잔 + 아이스티 2잔 → 한 줄에 3잔 / 9,000원. 다른 음료 1잔을 주문하면 별도 줄에 추가되어야 합니다. 전체 금액도 일치하는지 확인하세요.

개념 2. 메서드는 계산 결과를 돌려줄 수 있다

java
static int sum(ArrayList<Order> cart) {

  for (Order order : cart) {
    total += order.price * order.qty;

return 값은 메서드를 호출한 위치에서 사용할 수 있습니다. 반면 void 메서드는 값을 돌려주지 않습니다.

앞 실습의 sum(cart)를 이번에는 직접 작성해 봅니다. Order 객체에는 가격과 수량만 저장하고, 합계 계산은 목록 전체를 받는 메서드 하나로 처리합니다.

먼저 한 번의 전투가 아니라, 행동 메뉴가 계속 나타나는 장면을 생각해 보세요. 공격(1)을 선택하면 몬스터의 HP가 20 감소하고, 회복(2)을 선택하면 내 HP가 15 증가합니다. 도망(0)을 선택해야만 종료합니다.

public class BattleLoop {
  static class Hero {
    int hp;

    Hero(int hp) {
      this.hp = hp;
    }
  }

  static class Monster {
    int hp;

    Monster(int hp) {
      this.hp = hp;
    }
  }

  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    Hero hero = new Hero(60);
    Monster monster = new Monster(100);

    while (true) {
      System.out.println("1. 공격  2. 회복  0. 도망");
      System.out.print("행동 선택: ");
      int action = sc.nextInt();
      // TODO 1: 0을 입력하면 전투를 종료하세요.

      if (action == 1) {
        // TODO 2: monster.hp를 20 감소시키세요.
        System.out.println("몬스터 HP: " + monster.hp);
      } else if (action == 2) {
        // TODO 3: hero.hp를 15 회복시키세요.
        if (hero.hp > 100) {
          hero.hp = 100;
        }
        System.out.println("내 HP: " + hero.hp);
      } else {
        System.out.println("없는 행동입니다.");
      }
    }
    System.out.println("전투가 종료되었습니다.");
    sc.close();
  }
}
