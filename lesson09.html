  • 영수증을 화면에 출력하는 것과 파일에 저장하는 것은 무엇이 다를까요?

실습 방법: 먼저 질문에 답하고, 해당 회차 폴더의 Java 파일을 열어 TODO를 작성합니다. 정답이 없는 상태의 파일이므로 직접 실행 결과를 확인하세요. 설명을 듣기 전에는 완성 코드를 찾아보지 않습니다.

개념 1. 조건에 따른 할인

이번에는 조건 ? 값1 : 값2라는 삼항 연산자가 등장합니다. 처음에는 익숙한 if로 풀고, 그 다음 짧은 표현을 배웁니다.

java
int total = 12000;
boolean student = true;
int discount = 0;
if (student) { // 학생이면
  discount = total / 10; // 10% 할인
}
System.out.println(total - discount); // 10800

student ? total / 10 : 0은 student가 참일 때 앞의 값, 거짓일 때 뒤의 값을 선택합니다. 새 문법을 외우기보다 같은 계산이라는 것을 먼저 확인하세요.

java
int total = 12000;
boolean student = true;
int discount = student ? total / 10 : 0; // 학생이면 10% 할인
// TODO: total에서 discount를 뺀 결과를 저장
System.out.println(total);
교사용 정답 보기 · 실습 해설
정답
total = total - discount;

10% 할인은 원래 금액의 90%를 받는다는 뜻입니다. int 계산에서 나눗셈은 소수점 아래를 버리므로, 계산 순서가 달라지면 결과가 달라질 수 있습니다.

개념 2. 잘못된 입력을 처리하기

Scanner.nextInt()는 글자가 들어오면 오류가 발생할 수 있습니다. 문자열로 입력받은 뒤 Integer.parseInt()로 바꿀 수도 있지만, 숫자로 바꿀 수 없는 글자를 받으면 NumberFormatException이 발생합니다.

java
try {
  int qty = Integer.parseInt(text); // 문자열 → 정수 변환 시도
  // TODO: 1 이상의 수량인지 검사
} catch (NumberFormatException e) {
  System.out.println("숫자를 입력하세요.");
}
교사용 정답 보기 · 수량 검사
정답
if (qty < 1) {
  System.out.println("1 이상의 숫자를 입력하세요.");
} else {
  System.out.println("주문 수량: " + qty);
}

try에서 오류가 나면 대응되는 catch로 이동합니다. 문자열이 숫자인지와 숫자가 유효한 범위인지는 다른 검사입니다.

문자열 숫자와 올바른 주문 수량은 다르다

"2"는 정수로 바꿀 수 있지만 "abc"는 바꿀 수 없습니다. 그리고 "-2"는 숫자로 바꿀 수 있어도 음료 수량으로는 잘못된 값입니다. 먼저 수량이 1 이상인지 if로 검사한 뒤 try-catch의 역할을 배웁니다.

java · 함께 입력
int qty = -2;
if (qty <= 0) {
  System.out.println("1잔 이상 입력하세요.");
}

try는 실행을 시도하는 부분, catch는 변환 실패처럼 예외가 발생했을 때 처리하는 부분입니다. 파이썬의 try/except와 비슷합니다.

실습 2. 수량 입력 검증

파일: SafeInput.java · 09_키오스크_결제/SafeInput.java

아래 코드를 파일에 입력하고 TODO를 완성한 뒤 실행하세요.

java · 실습 코드
import java.util.Scanner;
public class SafeInput {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    while (true) {
      System.out.print("수량 입력: ");
      String text = sc.nextLine();
      try {
        // 글자를 정수로 바꾸는 과정에서 오류가 날 수 있다.
        int qty = Integer.parseInt(text);
        // TODO: 양수일 때만 주문을 확정한다.
        // 학생 작성: qty가 1 이상일 때만 출력하고 반복 종료
        System.out.println("1 이상의 숫자를 입력하세요.");
      } catch (NumberFormatException e) {
        // 숫자로 바꿀 수 없는 입력을 처리한다.
        System.out.println("숫자만 입력하세요.");
      }
    }
    sc.close();
  }
}

실습 3. 카드 또는 현금으로 결제하기

할인 계산 다음에는 결제 방법을 선택합니다. 카드는 결제가 완료되었다는 메시지를 표시하고, 현금은 받은 금액에서 결제 금액을 뺀 거스름돈을 계산합니다. 실제 결제 장치에 연결하지 않는 콘솔 실습입니다.

파일: Payment.java

먼저 10,000원에서 10%를 할인하면 9,000원이라는 것을 계산해 보세요. 그다음 ① 카드 ② 현금 ③ 취소를 각각 입력해 실행 결과를 비교합니다.

java · 실습 코드
import java.util.Scanner;
public class Payment {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int total = 10000;
    int discount = total / 10;
    int due = total - discount;
    System.out.println("주문 금액: " + total + "원");
    System.out.println("할인 금액: " + discount + "원");
    System.out.println("결제 금액: " + due + "원");
    System.out.println("1. 카드  2. 현금  0. 결제 취소");
    System.out.print("선택: ");
    int method = sc.nextInt();
    if (method == 1) {
      System.out.println("카드 결제가 완료되었습니다.");
    } else if (method == 2) {
      System.out.print("받은 금액: ");
      int cash = sc.nextInt();
      // TODO 1: 낸 돈이 결제 금액보다 적으면 부족 안내
      // TODO 2: 충분하면 거스름돈 출력
    } else if (method == 0) {
      System.out.println("결제를 취소했습니다.");
    } else {
      System.out.println("없는 결제 방법입니다.");
    }
    sc.close();
  }
}

if (cash < due) {
  System.out.println("결제금액이 부족합니다.");
} else {

}

확인할 입력: 카드(1), 현금 10,000원(2), 현금 8,000원(2), 결제 취소(0), 없는 번호(5). 현금 8,000원에서는 거스름돈이 출력되면 안 됩니다.

선택 실습 안내 — 파일 저장

필수 목표는 할인 금액 계산, 유효한 수량 입력, 카드·현금 결제입니다. 영수증 파일 저장은 시간이 남으면 진행하는 선택 실습입니다.

개념 3. 영수증을 파일에 저장하기

Files.writeString(Path.of("receipt.txt"), 내용)을 이용하면 글자를 텍스트 파일로 저장할 수 있습니다. 파일은 프로그램 실행 위치를 기준으로 만들어질 수 있으므로 저장 위치도 확인해야 합니다.

다른 프로그램에 응용 — 게임의 안전한 입력

8회차의 전투에서는 0, 1, 2 중 하나를 숫자로 입력한다고 가정했습니다. 이번에는 5처럼 없는 번호나 abc처럼 숫자가 아닌 글자를 입력해도 다시 선택할 수 있도록 고칩니다.

먼저 이전에 배운 continue를 떠올려 보세요. continue는 현재 반복을 건너뛰고 다음 반복으로 넘어갑니다. 이번 예제에서는 잘못 입력한 경우 메뉴를 다시 보여주는 데 사용합니다.

숫자가 아닌 문자를 입력하면 Integer.parseInt()에서 NumberFormatException이 발생할 수 있습니다. try-catch는 이 오류를 처리하며 프로그램이 갑자기 끝나지 않도록 도와줍니다. 이 부분은 제공 코드로 사용하고, 학생은 번호 검사와 종료 조건을 직접 작성합니다.

실습 4. 잘못된 행동 번호 처리하기

SafeBattle.java — 8회차의 반복 전투를 입력 검증 중심으로 단순화한 예제입니다.

java
import java.util.Scanner;
public class SafeBattle {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    while (true) {
      System.out.println("1. 공격  2. 회복  0. 도망");
      System.out.print("행동 선택: ");
      String text = sc.nextLine();
      int action;
      try {
        // 문자열을 정수로 변환한다.
        action = Integer.parseInt(text);
      } catch (NumberFormatException e) {
        System.out.println("숫자를 입력하세요.");
        continue;
      }
      // TODO 1: 0, 1, 2가 아니면 안내 후 다시 입력받으세요.
      // TODO 2: 0이면 반복문을 종료하세요.
      if (action == 1) {
        System.out.println("공격!");
      } else if (action == 2) {
        System.out.println("체력 회복!");
      }
    }
    sc.close();
  }
}

테스트: abc를 입력하면 “숫자를 입력하세요.”, 5를 입력하면 “없는 행동 번호입니다.”가 각각 한 번 나오고 메뉴가 다시 표시되어야 합니다. 0을 입력하면 종료됩니다.

교사용 정답 보기 · SafeBattle.java
