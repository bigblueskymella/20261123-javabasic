실습 1. 먼저 한 번만 주문

아직 반복문이 없는 코드입니다. 실행한 뒤 불편한 점을 먼저 이야기합니다.

Once.java

java
import java.util.Scanner;
public class Once {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int total = 0;
    System.out.print("1 아이스티(3000원): ");
    int menu = sc.nextInt();
    if (menu == 1) {
      total += 3000;
    }
    System.out.println("합계: " + total);
    sc.close();
  }
}

코드를 입력하며 확인할 점

  • 메뉴를 한 번만 읽으므로 두 번째 주문을 받을 수 없습니다.
  • 무엇을 되풀이해야 하는지 말로 설명한 후 다음 단계로 넘어갑니다.

개념 먼저 배우기 — while은 무엇을 반복할까?

while은 조건이 참인 동안 중괄호 { } 안의 코드를 반복 실행하는 문법입니다. 아래 예제는 count가 3보다 작거나 같은 동안 출력합니다.

java
int count = 1;
while (count <= 3) { // count가 3 이하인 동안 반복
  System.out.println(count); // 1, 2, 3을 차례대로 출력
  count++; // 1씩 증가하지 않으면 반복이 끝나지 않음
}
System.out.println("반복 끝");

실행 전 질문: count++를 지우면 어떻게 될까요? 왜 그런지 먼저 이야기한 다음 실행해 봅니다. 끝나지 않으면 실행 중지 버튼을 누릅니다.

while (true)와 break

키오스크는 주문 횟수를 미리 알 수 없습니다. 그래서 조건을 항상 참으로 둔 while (true)로 반복하고, 종료 메뉴를 선택했을 때 break로 반복을 빠져나옵니다. break는 if 조건이 아니라 반복문을 중단시키는 명령입니다.

java
int number = 1;
while (true) { // 종료 명령을 만날 때까지 반복
  System.out.println(number);
  if (number == 3) { // 3이 되면 반복을 중단
    break;
  }
  number++;
}
System.out.println("종료");

코드를 입력하고 확인할 점

  • while (조건)에서 조건이 참일 때 반복합니다.
  • if (조건)은 조건이 참일 때 한 번 실행할 코드를 고릅니다.
  • break를 만나면 반복문 아래쪽 코드로 이동합니다.
  • 종료 조건이 없으면 프로그램이 계속 돌아갈 수 있습니다.

같은 원리를 더 짧게 연습하기

기본 연습: 종료 조건을 다른 예제로 확인

while은 조건이 참인 동안 반복합니다. break는 즉시 반복을 끝냅니다. 먼저 숫자가 3이 되었을 때 반복을 멈추는 코드를 함께 입력해 보세요.

java · 함께 입력
int count = 0;
while (true) {
  count++;
  if (count == 3) {
    break;
  }
}
System.out.println(count); // 3

이제 같은 원리로 menu가 0일 때 break를 실행하는 코드를 작성합니다.

실습 2. 종료 조건 직접 작성

앞에서 while, if, break를 사용해 봤습니다. 이제 같은 원리를 키오스크의 주문 종료 기능에 적용합니다.

Repeat.java

java
import java.util.Scanner;
public class Repeat {

    while (true) { // 조건이 항상 참이므로 반복한다.
      System.out.print("1 아이스티 / 0 종료: ");
      int menu = sc.nextInt();
      // TODO 1: menu가 0이면 break로 반복을 끝내세요.
      // TODO 2: menu가 1이면 주문 확인 문구를 출력하세요.
    }
    System.out.println("주문 종료");
    sc.close();
  }
}

실습 3. 총금액 누적

이제 반복되는 주문의 가격을 더해 봅니다. 먼저 아래의 짧은 계산을 입력해서 +=를 복습합니다.

java
int total = 0;
total += 3000; // total = total + 3000;과 같음
total += 3500;
System.out.println(total); // 6500

왜 total은 반복문 밖에 있어야 할까요? 반복할 때마다 int total = 0;을 다시 실행하면 앞선 주문 금액을 잃기 때문입니다. 이제 실제 주문 메뉴로 옮겨 봅니다.

Total.java

java
import java.util.Scanner;
public class Total {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int total = 0; // 반복문 밖: 주문 사이에도 값을 유지한다.
    while (true) {
      System.out.print("1 아이스티 / 2 초코라테 / 0 종료: ");
      int menu = sc.nextInt();
      if (menu == 0) {
        break;
      }
      // TODO: 1이면 3000원, 2이면 3500원을 합계에 더하세요.
      // TODO: 잘못된 번호일 때는 합계를 바꾸지 마세요.
    }
    System.out.println("결제 예상금액: " + total + "원");
    sc.close();
  }
}

  • for는 반복 횟수가 분명할 때 유용합니다. 다만 앞에서 배우지 않았다면 아래 예제를 먼저 직접 실행합니다.

개념 배우기 — for문은 어떻게 동작할까?

while이 조건이 참인 동안 계속 실행하는 반복문이라면, for는 몇 번 반복할지 알 때 자주 사용합니다. 예를 들어 몬스터를 3번 공격하거나, 주문 번호 1번부터 5번까지 차례대로 출력할 때 사용합니다.

1. for문의 기본 구조

java
for (int i = 1; i <= 3; i++) {
  System.out.println(i + "번째 반복");
}

이 코드를 실행하면 1번째 반복, 2번째 반복, 3번째 반복이 출력됩니다.

부분 의미 실행 순서
int i = 1 반복을 시작할 때 i를 1로 만듭니다. 처음에 딱 한 번
i <= 3 i가 3 이하인지 검사합니다. 반복할 때마다
{ ... } 조건이 참이면 중괄호 안의 코드를 실행합니다. 조건 검사 후
i++ 본문을 실행한 뒤 i를 1 증가시킵니다. 본문 다음

실행 순서: 초기화(1회) → 조건 검사 → 본문 실행 → 증가 → 다시 조건 검사. 조건이 거짓이면 반복문이 끝납니다.

2. 직접 입력하며 결과 확인하기

ForCount.java — 아래 코드는 처음부터 직접 입력합니다.

java
public class ForCount {
  public static void main(String[] args) {
    // i = 1에서 시작해 5까지 1씩 증가시킨다.
    for (int i = 1; i <= 5; i++) {
      System.out.println("카운트: " + i);
    }
    System.out.println("반복 종료");
  }
}

실행 전에 먼저 질문합니다.

  • i <= 5를 i < 5로 바꾸면 몇 번 출력될까요? (<는 미만, <=는 이하)
  • i++를 i += 2로 바꾸면 어떤 숫자가 출력될까요?
  • i <= 5를 i >= 5로 바꾸면 시작값이 1일 때 본문은 몇 번 실행될까요?

각 질문은 예상 → 한 줄 수정 → 실행 → 확인 순서로 진행합니다. 원래 코드를 다시 돌려놓고 다음 문제로 넘어갑니다.

6. while과 for 비교하기

상황 추천 문법 이유

미니 프로젝트 — 숫자 업다운 게임

선택 실습 · 약 25~35분. 손님이 0을 누를 때까지 주문받던 while을 응용해, 정답을 맞힐 때까지 계속 숫자를 입력받습니다.

먼저 생각하기: 정답이 6이라면 8을 입력했을 때는 DOWN, 4를 입력했을 때는 UP을 출력해야 합니다. 맞히면 무한 반복을 어떻게 끝낼까요?

숫자를 무작위로 정하는 줄은 제공 코드입니다. Math.random()의 자세한 계산 원리는 나중에 배우고, 지금은 1~10 사이의 숫자를 만든다는 것만 이해하면 됩니다.

파일: `UpDown.java` · 입력과 반복은 제공된 틀을 함께 입력하고, 비교 조건과 종료 코드를 완성하세요.

java
import java.util.Scanner;
public class UpDown {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    // 정답은 1부터 10 사이의 임의의 숫자입니다.

      int guess = sc.nextInt();

    }
