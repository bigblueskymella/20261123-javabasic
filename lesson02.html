실습 1. 입력받기

먼저 이름과 숫자를 입력받습니다.

Ask.java

java
import java.util.Scanner;
public class Ask {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    System.out.print("이름: ");
    String name = sc.nextLine(); // 한 줄의 글자를 입력받는다.
    System.out.print("레벨: ");
    int level = sc.nextInt(); // 정수를 입력받는다.
    System.out.println(name + " 레벨 " + level);
    sc.close();
  }
}

코드를 입력하며 확인할 점

  • import는 다른 패키지의 클래스를 사용하도록 가져옵니다.
  • 정수가 아닌 글자를 nextInt()로 읽으면 예외가 발생할 수 있습니다.

조건문을 쓰기 전에 점검하기

파이썬의 if score > 100:과 같은 역할입니다. 자바에서는 조건을 소괄호로 감싸고 실행할 코드를 중괄호로 묶습니다.

java · 함께 입력
int score = 115;
if (score > 100) {
  score = 100;
}
System.out.println(score); // 100

점수가 80일 때와 115일 때 각각 어떤 결과가 나올지 먼저 예상해 보세요.

실습 2. 게임 선택

공격과 회복 중 하나를 선택하게 합니다. 아래의 짧은 예제로 조건 검사를 연습한 다음 회복 제한을 직접 작성합니다.

먼저 배우기: 값이 정해진 최대치를 넘지 않도록 제한하기

java
int score = 115;
if (score > 100) { // 점수가 100보다 크면
  score = 100; // 점수를 100으로 바꾼다.
}
System.out.println(score); // 100

if (조건)은 조건이 참일 때만 중괄호 안을 실행합니다. >는 왼쪽 값이 더 크다는 뜻입니다. 이제 똑같은 방법으로 캐릭터 HP도 100을 넘지 않게 해보세요.

Choice.java

java
import java.util.Scanner;
public class Choice {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int hp = 90;
    System.out.print("1 공격 / 2 회복: ");
    int action = sc.nextInt();
    if (action == 1) {
      System.out.println("몬스터 공격!");
    } else if (action == 2) {
      hp += 35;
      System.out.println("회복 후 HP: " + hp);
    } else {
      System.out.println("없는 행동입니다.");
    }
    // TODO: 회복 후 hp가 100보다 크면 100으로 바꾸세요.
    // 힌트: 위 score 예제의 if 조건과 대입문을 hp에 적용하세요.
    sc.close();
  }
}
교사용 정답 보기 · Choice.java 완성 코드
Choice.java
if (hp > 100) {
  hp = 100;
}

코드를 입력하며 확인할 점

  • ==는 두 값이 같은지 검사하고, =는 값을 저장합니다.
  • else if는 앞 조건이 거짓일 때 다음 조건을 검사합니다.
  • HP가 90인 상태에서 35를 회복하면 125가 됩니다. if로 최대 체력 100을 넘지 않도록 고쳐 봅시다.

미니 프로젝트 1 — 가위바위보

선택 실습 · 약 25~35분. 앞서 배운 입력과 조건문을 게임에 적용합니다. 컴퓨터가 바위(0)를 내는 간단한 버전부터 시작합니다.

먼저 표로 예상하세요: 사용자가 0을 선택하면 무승부, 1은 패배, 2는 승리입니다. 3처럼 범위를 벗어난 입력은 오류로 처리합니다.

추가 문법: ||는 둘 중 하나라도 참이면 참입니다. 예: player < 0 || player > 2는 0~2 범위를 벗어났는지 검사합니다.

파일: `Rps.java` · 아래 시작 코드를 함께 입력한 뒤 TODO 조건문을 완성하세요.

java
import java.util.Scanner;
public class Rps {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    // 첫 연습은 컴퓨터가 항상 바위(0)를 냅니다.
    int computer = 0;
    System.out.print("0 바위 / 1 가위 / 2 보: ");
    int player = sc.nextInt();
    // TODO 1: 같은 번호면 "무승부"를 출력하세요.
    // TODO 2: player가 2이면 "승리", 1이면 "패배"를 출력하세요.
    // TODO 3: 0, 1, 2 이외의 번호면 "잘못된 입력"을 출력하세요.
    sc.close();
  }
}
교사용 정답 보기 · Rps.java · 조건문
java
if (player < 0 || player > 2) {
  System.out.println("잘못된 입력");
} else if (player == computer) {
  System.out.println("무승부");
} else if (player == 2) {
  System.out.println("승리");
} else {
  System.out.println("패배");
}

기존 연습에서는 컴퓨터가 항상 바위를 냈습니다. 이제 랜덤으로 선택한 가위·바위·보에도 승패 판정이 올바르게 동작하도록 바꿔 봅시다.

추가 연습 — 컴퓨터도 랜덤으로 가위바위보 하기

Math.random()은 0 이상 1 미만의 실수를 만듭니다. 여기에 3을 곱하고 (int)로 소수점을 버리면 0, 1, 2 중 하나를 얻습니다. 이번 실습에서는 이 한 줄을 제공 코드로 사용합니다.

java
int computer = (int) (Math.random() * 3);

1단계. Rps.java의 int computer = 0;을 위 코드로 교체하세요. 두 선언을 동시에 남기면 변수 중복 오류가 발생합니다. 숫자의 의미는 0 바위 / 1 가위 / 2 보로 유지합니다.

2단계. 컴퓨터가 무엇을 냈는지 출력해 보세요. 기존 사용자 입력을 받는 코드 다음에 아래 조건문을 추가합니다.

java
if (computer == 0) {
 System.out.println("컴퓨터: 바위 ✊");
} else if (computer == 1) {
 System.out.println("컴퓨터: 가위 ✌️");
} else {
 System.out.println("컴퓨터: 보 ✋");
}

3단계 — 학생 미션. 기존 승패 판정은 컴퓨터가 바위일 때만 맞는 코드입니다. 컴퓨터가 가위나 보를 내더라도 맞게 작동하도록 수정해 보세요. 사용자가 0·1·2 이외의 값을 입력했을 때도 검사해야 합니다.

생각할 조건: 바위(0)는 가위(1)를 이기고, 가위(1)는 보(2)를 이기고, 보(2)는 바위(0)를 이깁니다. 나머지는 무승부 또는 패배입니다.

교사용 정답 보기 · Rps.java · 랜덤 선택 승패 판정
java
if (player < 0 || player > 2) {
 System.out.println("잘못된 입력입니다.");
} else if (player == computer) {
 System.out.println("무승부!");
} else if ((player == 0 && computer == 1)
 || (player == 1 && computer == 2)
 || (player == 2 && computer == 0)) {
 System.out.println("승리!");
} else {
 System.out.println("패배!");
}

확인하기. 게임을 5번 이상 실행하면서 컴퓨터의 선택이 바뀌는지 보고, 바위·가위·보 각각의 승리·패배·무승부를 확인해 보세요. 동일한 결과가 연속해서 나올 수도 있습니다.

미니 프로젝트 2 — 재미로 하는 4문항 MBTI

선택·심화 실습 · 약 30~45분. 네 번의 질문에 답하면서 String에 글자를 이어 붙이는 연습입니다. 과학적인 성격 진단이 아니라 수업용 놀이입니다.

mbti += "E";는 mbti = mbti + "E";와 같습니다. 각 문항에서 1번 또는 2번을 선택하면 결과에 글자가 하나씩 추가됩니다.

파일: `MbtiTest.java` · 첫 질문의 분기부터 작성해 실행하고, 같은 방법으로 Q2~Q4를 완성하세요. 먼저 1 또는 2만 입력한다고 가정합니다.

java
import java.util.Scanner;
public class MbtiTest {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    String mbti = "";
    System.out.println("재미로 하는 4문항 성향 테스트");
    System.out.println("각 문항에 1 또는 2를 입력하세요.");
    System.out.println("[Q1] 약속이 취소되면?");
    System.out.println("1. 친구를 더 만나고 싶다 / 2. 혼자 쉬고 싶다");
    int q1 = sc.nextInt();
    // TODO 1: q1이 1이면 E, 2이면 I를 mbti에 붙이세요.
    System.out.println("[Q2] 사과하면 떠오르는 건?");
    System.out.println("1. 빨간 과일 / 2. 백설공주나 뉴턴");
    int q2 = sc.nextInt();
    // TODO 2: q2가 1이면 S, 2이면 N을 붙이세요.
    System.out.println("[Q3] 친구가 시험을 망쳤다면?");
    System.out.println("1. 해결 방법을 생각한다 / 2. 먼저 위로한다");
    int q3 = sc.nextInt();
    // TODO 3: q3이 1이면 T, 2이면 F를 붙이세요.
    System.out.println("[Q4] 친구와 여행을 간다면?");
    System.out.println("1. 일정을 짠다 / 2. 즉흥적으로 다닌다");
    int q4 = sc.nextInt();
    // TODO 4: q4가 1이면 J, 2이면 P를 붙이세요.
    System.out.println("나의 4글자 결과: " + mbti);
    sc.close();
  }
}
